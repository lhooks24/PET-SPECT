# Imaging Methods: 1D Ultrasound Simulations

This project contains three progressively more complete baseline models of
one-dimensional acoustic propagation and a nonlinear pulse-inversion
extension. The finalized layered model is
`scripts/1DWaveSimulationLayered.py`. It simulates a 2 MHz pulse emitted by an
ideal piezoelectric face into a water–dermis–water–PMMA stack, including signed
interface reflections, transmissions, finite-layer reverberations, a virtual
receive voltage, a static A-scan, and an interactive distance study.

These programs illustrate wave physics and experimental interpretation. They
are not validated clinical, metrology, or transducer-design tools.

sound-speed boundary; `1DWaveSimulationDensity.py` adds density, impedance, and

intermediate model documented below. `NonlinearPulseInversion.py` is a separate
follow-on investigation and does not alter that baseline.

## Running the finalized layered model

Open the static dashboard with a seeded random geometry:

```powershell
uv run python .\1DWaveSimulationLayered.py
```

Run the experimentally motivated geometry used during development:

```powershell
uv run python .\1DWaveSimulationLayered.py `
  --a-mm 49.3 --b-mm 25.4 --c-mm 42.3 --d-mm 5.8 `
  --source-pressure-mpa 1
```

Here `a` is the external water standoff from the piezo face to the skin front,
`b` is dermis thickness, `c` is the second water layer, and `d` is PMMA
thickness. Command-line distances are in millimeters.

Save a canonical figure and CSV without opening a window:

```powershell
uv run python .\1DWaveSimulationLayered.py `
```

The CSV includes time, imposed source pressure, acoustic receiver pressure,

dashboard.

### Interactive GUI

```powershell
uv run python .\1DWaveSimulationLayered.py --animate
```

In GUI mode, `a` defaults to 49.3 mm. Eleven complete FDTD acquisitions are
precomputed over approximately 49.3 ± 25 mm; the lower endpoint is increased if
needed to enforce `b < a`. Startup therefore takes longer, but slider selection
is immediate. The left panel animates pressure independently. The right panel
always displays a complete, static voltage trace on one fixed time axis. A–F
are peak-aligned and color-coded for every cached geometry.

Use `--interval 40` to set a 40 ms animation delay, `--seed` to change the
reproducible static random geometry, and `--help` to list every option.

## Geometry and echo definitions

```text
rigid ideal piezo | water a | dermis b | water c | PMMA d | water/sponge
```

The named arrivals are path hypotheses used to label wavelets generated by the
FDTD solver:

| Echo | Path | Nominal center time |
|---|---|---|
| A | Skin-front reflection | `t0 + 2a/cw` |
| B | Skin-back reflection | `t0 + 2a/cw + 2b/cs` |
| C | Second round trip between piezo and skin front | `t0 + 4a/cw` |
| D | PMMA-front reflection | `t0 + 2a/cw + 2b/cs + 2c/cw` |
| E | PMMA rear-face reflection | `tD + 2d/cp` |
| F | First additional PMMA round trip | `tD + 4d/cp` |

Here `cw`, `cs`, and `cp` are sound speeds in water, dermis, and PMMA, and
`t0` is the emitted burst center. The formulas predict labeling locations; they
do not synthesize the echoes. All interface interactions and higher-order paths
arise from numerical propagation.

## Governing equations

The solver uses the linear, lossless, first-order acoustic equations for a
spatially varying fluid-like medium:

```text
rho(x) dv/dt = -dp/dx
dp/dt = -K(x) dv/dx
K(x) = rho(x)c(x)^2
```

Pressure is `p`, longitudinal particle velocity is `v`, density is `rho`, sound
speed is `c`, and bulk modulus is `K`. In a homogeneous region these equations
give `d²p/dt² = c²d²p/dx²`. Plane-wave characteristic impedance is `Z=rho*c`.

At normal incidence from material 1 into material 2, continuity of pressure and
normal velocity gives

```text
Rp = (Z2 - Z1)/(Z2 + Z1)
Tp = 2Z2/(Z1 + Z2)
RI = |Rp|²
TI = 4Z1Z2/(Z1 + Z2)² = 1 - RI.
```

`Rp` and `Tp` are pressure-amplitude coefficients; `RI` and `TI` are intensity
fractions for lossless media. A negative `Rp` phase-inverts the RF echo.
Successive reverberations acquire the product of each encountered reflection
and transmission coefficient. Scaling source pressure scales every pressure
and ideal voltage linearly but does not change their ratios.

## Staggered-grid FDTD method

Pressure is stored at cell centers and velocity at faces. This discretizes the
coupled conservation laws and handles density discontinuities more faithfully
than a homogeneous second-order wave equation. Face density is the harmonic
mean `2*rho_left*rho_right/(rho_left+rho_right)`. The leapfrog updates are

```text
v(i+1/2,n+1/2) = v(i+1/2,n-1/2)
                 - dt/(rho_face*dx) [p(i+1,n)-p(i,n)]

p(i,n+1) = p(i,n)
           - K(i)dt/dx [v(i+1/2,n+1/2)-v(i-1/2,n+1/2)].
```

Grid spacing is 25 µm, giving approximately 30 cells per water wavelength at
2 MHz. The time step satisfies the one-dimensional Courant condition
`max(c)dt/dx=0.90<1`. Smooth edge sponges suppress remote boundary echoes;
they are not physical bulk attenuation. Zero normal velocity at the piezo face
makes it an ideal rigid reflector with pressure coefficient +1. This enables
transducer–sample reverberation C but overestimates reflection from a real
receiving transducer.

## Source and ideal receiver

The source is a three-cycle Gaussian-windowed sinusoid:

```text
p_source(t) = P0 sin[2*pi*f0(t-tc)] exp[-0.5((t-tc)/sigma)²],
f0 = 2 MHz.
```

Default `P0` is 1 MPa and is adjustable with `--source-pressure-mpa`. It is an
imposed acoustic source, not a prediction from drive circuitry.

The receive model applies a real, symmetric Gaussian frequency response
centered at 2 MHz with an assumed 80% amplitude fractional bandwidth at -6 dB
and no phase delay. Filtered pressure becomes ideal open-circuit voltage via
`V(t)=Sv*p_filtered(t)`, with illustrative sensitivity `Sv=1 V/MPa`. These are
not calibrated properties of a particular transducer.

## Assumptions and limitations

The finalized model assumes one dimension, normal incidence, plane
longitudinal waves, flat parallel interfaces, linear acoustics, homogeneous
isotropic fluid-like layers, perfect coupling, and pressure-independent
properties. It omits physical attenuation and dispersion, nonlinear
propagation, heating, shear waves, geometric spreading, diffraction, focusing,
angular refraction, surface roughness, air gaps, membranes, adhesives, and
sample-holder walls.

It also omits real transmit feedthrough, piezo electromechanical loading,
cables, matching networks, receiver gain, oscilloscope filtering, clipping,
and electrical noise. Because the model is 1D, “transmission” is more precise
than angular “refraction”: speed and wavelength change, but no ray angle exists.
The model is most useful for arrival-time reasoning, impedance-controlled echo
signs and trends, and ideal multiple-reflection paths. Absolute agreement with
hardware requires measured source pressure, transducer transfer functions,
receive-chain calibration, and every physical layer in the apparatus.

## Extension: nonlinear pulse-inversion imaging

`scripts/NonlinearPulseInversion.py` replaces the exploratory template-based
echo-separation program. It models a weak even-order nonlinear target whose echo
is superimposed on a much stronger linear reflector. Two acquisitions use
opposite-polarity transmit pulses. Linear echoes reverse sign, while the
even-order target response does not, so their half-sum suppresses the linear
reflector without requiring a stored reflector waveform.

In the idealized model,

```text
y_plus  = +L + N + noise_plus
y_minus = -L + N + noise_minus
(y_plus + y_minus)/2 = N + averaged noise
```

`L` is the strong linear reflection and `N` is the weak even-order nonlinear
response near twice the 2 MHz transmit frequency. The validation plot includes
the simulated true `N` only to score the recovery; the half-sum algorithm does
not use it. The default target is 0.5 mm behind the reflector, close enough for
their finite-duration echoes to overlap.

Run the interactive dashboard from the scripts directory:

```powershell
uv run python .\NonlinearPulseInversion.py
```

Save a reproducible figure and recovery table without opening a window:

```powershell
uv run python .\NonlinearPulseInversion.py `
  --save-figure ..\outputs\figures\nonlinear_pulse_inversion.png `
  --save-animation ..\outputs\figures\nonlinear_pulse_inversion.gif `
  --save-csv ..\outputs\data\nonlinear_pulse_inversion.csv `
  --no-show
```

Use `--nonlinear-fraction` and `--noise-fraction` to change target difficulty.
`--inversion-gain-error` and `--inversion-time-error-ns` deliberately make the
second transmission imperfect, demonstrating how linear clutter leaks into the
recovered channel. The animation moves the nonlinear target through the linear
reflector. This method cannot separate two arbitrary linear echoes: it works
because the second acquisition supplies a different nonlinear response.

This remains a 1D signal-level study. The strong reflector can represent
bone-like clutter, but the model does not include elastic propagation, shear
conversion, irregular bone geometry, or a prediction of transmission through
actual bone. The even-order target is representative of a nonlinear scatterer
such as a contrast-agent response; ordinary linear anatomy would cancel with
the reflector instead of surviving pulse inversion.
